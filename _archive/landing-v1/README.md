# Archived landing page (v1)

The landing page as it was on `master` before the 2026-10 redesign: `about.md` (page content),
`about.liquid` (layout) and `footer.liquid` (the copyright footer, since removed site-wide).
The portrait it used, `assets/img/pic2026.png`, is still in place.

This folder starts with an underscore, so Jekyll does not build or publish it.
It is also tagged in git as `archive/landing-v1` (points at the last `master` commit before the redesign).

To restore: copy `about.md` to `_pages/` and `about.liquid` to `_layouts/`.
